# Testing the Site Visualization

## Local Dev Server

The site is a static HTML page with inline JS. Serve it locally:

```bash
cd site && python3 -m http.server 8000
```

Then open `http://localhost:8000` in Chrome.

## Vercel Preview

Vercel deploys previews for PRs. The preview URL may require Vercel team authentication (returns 401). If so, fall back to local serving.

## Key Testing Areas

### Treemap Rendering
- Page should show a full treemap with coloured rectangles grouped by SOC major group (1-9)
- D3 is loaded from CDN with SRI integrity check — if the script tag is wrong, the treemap won't render and you'll see "Could not load data.json" or a blank chart
- Check browser console for D3 version: `d3.version` should return the pinned version

### Tooltip (Hover)
- Hover any treemap cell to see the tooltip
- Tooltip shows: title, SOC code, major group label, risk category, AI score, pay, employment, growth, timeline, rationale
- Fields with `&` (e.g. "Managers, Directors & Senior Officials") should render as literal characters, not as `&amp;` (double-encoding)
- The `esc()` function handles HTML escaping — test via console: `esc('<script>alert(1)</script>')` should return `&lt;script&gt;alert(1)&lt;/script&gt;`

### Filters
- **Entry-level only**: Checkbox filters to `entry_level == true` — treemap should show fewer cells, dominated by SOC groups 6-9
- **High-risk entry-level**: Filters to `entry_level_risk == true` — even fewer cells
- **Public sector**: Filters to `public_sector == true`
- **Apprenticeship**: Filters to `apprenticeship_available == true`
- After toggling any filter, treemap re-renders immediately

### Colour Modes
- **AI exposure** (default): Green (low) → Red (high), legend reads "lower exposure / higher exposure"
- **Employment growth**: Red (declining) → Green (growing), legend reads "declining / growing"
- Cell badges switch between AI score (e.g. "5.5") and growth percentage (e.g. "+8.7%")

### Data Pipeline
- `data.json` in `site/` is the frontend payload, generated by `scripts/merge.py`
- If data.json is missing or malformed, the page shows an error message in the chart area
- Data originates from LLM scoring (rationale, safer_pivot) and scraped NCS content — treat these fields as untrusted input

## Devin Secrets Needed

None for site testing. The `ANTHROPIC_API_KEY` secret is only needed if re-running the scoring pipeline (`scripts/score.py`).
